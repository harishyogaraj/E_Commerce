# VISTA — E-Commerce Product Listing

React + TypeScript + Tailwind product catalog with filtering, sorting, favorites, and pagination.

## Setup

```bash
npm install
npm run dev
```

## Features

- Product grid (image, name, price, category, rating)
- Filter by category and minimum rating
- Sort by price, rating, or name
- Favorites with localStorage persistence
- Client-side pagination
- Lazy-loaded product images
- Sticky filter sidebar
